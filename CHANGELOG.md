## [0.1.0] - 2026-09-24

### Added

- Multi-vendor architecture council for GitHub Spec Kit.
- Thirteen planner, critic, synthesis, and validation personas.
- Independent and disclosed review passes with fresh model context for every invocation.
- Mandatory Codex and Anthropic validation, optional additional vendors, and explicit human
  decisions.
- Architecture-only provider boundary, transcript provenance, secret scanning, resumable runs, and
  a hard `READY` gate before task generation.
- Spec Kit extension, workflow, preset, bundle, catalogs, and offline verification.
